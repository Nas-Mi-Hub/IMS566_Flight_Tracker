# ✈️ AeroTrack - Flight Tracker System

## Project Description
AeroTrack is a front-end web application designed to act as a flight tracker dashboard for airport administration. It allows admins to view flight statuses, manage fleet data, and see visual summaries of daily operations.

## Features Included
* **Simulated Authentication:** Hardcoded login system with error feedback for incorrect credentials.
* **Responsive Navigation:** A mobile-friendly Bootstrap 5 navigation bar linking all system pages.
* **Interactive Dashboard:** Displays a summary of on-time, delayed, and cancelled flights, alongside a data visualisation chart.
* **Data Visualisation:** A Bar Chart built with Chart.js showing the distribution of flights per airline.
* **Multiple Data Views:** * *Active Flights:* A tabular data view of current flights and their real-time statuses.
    * *Our Fleet:* A grid layout showcasing the types of aircraft currently registered in the system.
