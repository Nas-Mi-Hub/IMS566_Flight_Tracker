# ✈️ AeroTrack - Flight Tracker System

## Project Description
AeroTrack is a front-end web application designed to act as a flight tracker dashboard for airport administration. It allows admins to view flight statuses, manage fleet data, and see visual summaries of daily operations.

## Features Included
* **Enhanced Authentication:** Admin + User login with signup using localStorage.
* **6 Interactive Charts/Graphs** on Dashboard using Chart.js.
* **Book Now Feature:** Users and admins can book aircraft with form and confirmation.
* **Responsive Navigation:** Includes new "Book Now" tab.
* **Fleet:** 6 aircraft types available for booking.
* **Multiple Data Views:** Active Flights map, Fleet grid, etc.
